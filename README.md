
# ShopEase - E-Commerce Capstone

## Overview
ShopEase is a responsive e-commerce demo built using HTML, CSS,
and JavaScript. It demonstrates product management, cart operations,
and simulated authentication.

## Features
- Demo login and logout
- Interactive product catalog
- Search, category filters, and sorting
- Add, edit, and delete products (CRUD)
- Shopping cart with quantity and total
- Persistent product and cart data using localStorage
- Responsive mobile, tablet, and desktop layouts
- Demo checkout without real payments

## Technology Stack
- HTML5
- CSS3
- JavaScript ES6
- Browser localStorage

## Project Structure
- index.html: Application layout
- style.css: Styling and responsive design
- app.js: Application logic and state management
- README.md: Project documentation

## Architecture
User interaction
    -> HTML interface
    -> JavaScript event handlers
    -> Product and cart state
    -> Browser localStorage
    -> Updated interface

## Limitations
Authentication and checkout are simulated.
Data is stored in the current browser and is not shared
between different users or devices. This is a learning project,
not a secure production store.
